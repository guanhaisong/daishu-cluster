## 踩坑手册5例中文版（仓库里已附中文文件）

1. **PS5.1写文件带BOM**——AI员工写的配置文件"看着对但全崩"，根因是PowerShell 5.1的老毛病
2. **CDP端口重启就断**——进程活着≠端口活着，派单前必须双查
3. **截图截错窗口**——截屏截的是"屏幕上显示的"不是"你要的窗口"，用PrintWindow才对
4. **Electron主窗口是56x56小图标**——按PID枚举所有窗口挑最大的
5. **微信桥连发文件会休眠**——一件一件发，间隔开
